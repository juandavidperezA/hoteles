🚀 Proyecto: Sistema de Reservas de Hotel (modo consola)

Este está MUY alineado con cosas reales y además conecta con lo que ya has visto en tu proyecto Java 👀

🧠 Idea general

Un sistema donde puedas:

Registrar hoteles
Crear habitaciones
Hacer reservas
Ver disponibilidad
Guardar todo en JSON
🧩 Estructura de datos (más compleja)

Aquí ya no es una sola lista… ahora tienes relaciones.

🏨 Hotel
hotel = {
    "id": 1,
    "nombre": "Hotel Paraíso",
    "ciudad": "Cúcuta",
    "habitaciones": []
}
🛏️ Habitación
habitacion = {
    "id": 101,
    "tipo": "doble",
    "precio": 80000,
    "disponible": True
}
📅 Reserva
reserva = {
    "id": 1,
    "hotel_id": 1,
    "habitacion_id": 101,
    "cliente": "Brayan",
    "fecha": "2026/04/10"
}
🔥 Aquí está la complejidad real

Ahora tienes que manejar:

Relaciones entre datos (hotel → habitaciones)
Búsquedas por ID
Cambios de estado (disponible / no disponible)
Validaciones

1. Crear hotel
2. Agregar habitación a hotel

4. Ver habitaciones de un hotel
5. Hacer reserva
6. Cancelar reserva
7. Ver reservas
8. Salir
